# Bhoomi

Bhoomi is a full-stack e-commerce web application focused on women's health-related products, with an integrated blogging feature for community interaction and content sharing.

## Overview

Built as a complete online shopping platform, Bhoomi allows users to browse, search, and purchase products while engaging with health-related blog content. The application includes a full admin panel for managing products and orders, along with secure user authentication and a smooth shopping experience from cart to checkout.

## Features

- **User Authentication** – Secure sign-up and login with session-based authentication
- **Admin Panel** – Full CRUD operations for managing products, orders, and content
- **Product Search & Filter** – Search and filter products by category and attributes
- **Shopping Cart** – Add to cart, edit quantities, and manage cart items
- **Discounts** – Apply discounts on eligible products/orders
- **User Account Management** – Profile and account settings for users
- **Payment Confirmation** – Order checkout with payment confirmation flow
- **Blogging** – Blog section for women's health-related articles and community interaction

## Getting Started

### Prerequisites
- PHP server (e.g., XAMPP/WAMP)
- MySQL database(maria db inbuilt)

### Installation
1. Clone the repository
   ```bash
   git clone <repository-url>
   ```
2. Import the MySQL database schema from https://drive.google.com/drive/folders/1-6LuLrKeHpAMixXUlGw0-olIuicbbmxK(don't edit)
3. Configure database connection settings
4. Run the project on a local PHP server
